# Quick Reference: Gift Card Management

## TL;DR: 3 Steps to Manage Gift Cards

1. **Open** → AI Content Manager → Click "**Packages**" tab
2. **Filter** → Click "**Show: Gift Cards**" (at the top)
3. **Edit** → Select a gift card and ask AI to change it

---

## Common Tasks

### Add a New Gift Card
```
"Add a $50 gift card for massage services"
```
Or with more details:
```
"Create a $100 gift card. Description: Valid for 12 months, transferable. Include features: can be used for any service, no expiration fees."
```

### Update Gift Card Price or Details
```
"Change the $50 gift card to $60"
```
Or:
```
"Update the gift card description and add a feature about expiration"
```

### Apply Discount (Seasonal)
```
"Apply 10% off to all gift cards through December 31st"
```
This will:
- Show each gift card
- Add discount text: "10% off through 12/31"
- Display original price struck-through, new discounted price highlighted

### Remove/Delete a Gift Card
```
"Delete the $50 gift card"
```

---

## Tips

✅ **See Both Packages and Gift Cards?** Use the filter:
- Click "**Show: All**" to see everything
- Click "**Show: Packages**" to see only packages
- Click "**Show: Gift Cards**" to see only gift cards

✅ **Want to Preview?** After asking AI to change something:
- Look at the right panel (preview)
- You'll see the gift card display with your changes
- Price, discount, and features all visible

✅ **Made a Mistake?** Click "Undo" to restore the previous version

✅ **Language?** Switch between English and Thai:
- Click "EN" or "TH" at the top left
- Everything updates, including filter labels

---

## Discount Text Examples

When applying discounts, common formats are:
- "10% off" → Shows with struck-through original price
- "Save $20" → Shows savings amount
- "10% off through 12/31" → Includes expiration
- "Early bird special" → Custom text
